MATYPOCH.COM.AR — maqueta inicial

1. Subí el contenido de esta carpeta al repositorio que publique GitHub Pages.
2. En Settings > Pages > Custom domain configurá: matypoch.com.ar
3. En Cloudflare, apuntá el dominio raíz a GitHub Pages y www a diospoch.github.io.
4. Dejá Cloudflare en DNS only durante la validación inicial de GitHub Pages/HTTPS.
5. Activá Enforce HTTPS cuando GitHub lo habilite.

IMPORTANTE:
- Si reutilizás el repositorio /poch, con dominio personalizado el sitio podrá responder como https://matypoch.com.ar/ aunque el repositorio siga llamándose "poch".
- Si preferís orden, podés renombrar el repositorio a "matypoch". No es obligatorio para el dominio personalizado.
- Actualizar los enlaces sameAs del JSON-LD del index.html cuando tengamos los perfiles definitivos.
