MATYPOCH.COM.AR — sitio estático

PRUEBA LOCAL
1. Descomprimir la carpeta.
2. Abrir index.html con doble clic.
3. Música, Archivo y Biografía usan rutas relativas y funcionan localmente.

SUBIDA A GITHUB
Subir el CONTENIDO de esta carpeta a la raíz del repositorio de GitHub Pages.
El archivo CNAME debe quedar en la raíz y contiene: matypoch.com.ar

NOTA
Los enlaces externos a YouTube necesitan conexión a Internet.
Los metadatos canonical, sitemap y JSON-LD apuntan deliberadamente a https://matypoch.com.ar/
aunque el sitio se abra de forma local.
